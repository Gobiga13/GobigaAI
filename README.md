# GobigaAI

🚀 An AI-powered chat application built using React, TypeScript, Vite, and Node.js.

## 🌐 Live Demo

https://gobiga-ai-dqd1.vercel.app/

## 📖 Overview

GobigaAI is a modern AI chatbot application designed to provide users with an interactive conversational experience.

## ✨ Features

- AI-powered chatbot
- Real-time messaging
- Responsive design
- Fast performance
- Modern UI/UX

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Node.js
- AI API Integration
- Vercel

## 🚀 Installation

```bash
git clone https://github.com/Gobiga13/GobigaAI.git
cd GobigaAI
npm install
npm run dev

```
For the **About** section on the right side of GitHub, keep:

**Description:**
> AI-powered chat application built with React, TypeScript, Vite, and Node.js.

**Website:**
> https://gobiga-ai-dqd1.vercel.app/

This way the Vercel link appears only once in the README and once in the GitHub Website field, which is the standard professional setup.
